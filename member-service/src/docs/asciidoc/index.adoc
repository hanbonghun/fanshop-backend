== 개요

member-service는 회원 가입과 로그인을 담당하며, 로그인 시 발급한 JWT가 order-service의 주문 API 인증에 사용된다.

모든 엔드포인트는 `/api/v{version}` prefix를 가진다. 버전은 경로 세그먼트로 해석된다(`WebConfig`).

응답은 공통 래퍼 `ApiResponse`로 감싸진다.

[cols="1,3"]
|===
| 필드 | 설명

| `result` | 처리 결과. `SUCCESS` 또는 `ERROR`
| `data` | 성공 시 응답 본문. 실패 시 `null`
| `error` | 실패 시 에러 코드와 메시지. 성공 시 `null`
|===
